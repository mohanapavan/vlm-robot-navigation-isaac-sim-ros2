# Saved results for the hospital scene (`scene/slam.usd`)

Everything needed to run the project without mapping or detecting again. These are the results of one completed run;
nothing here is re-generated by the tests.

| file | what it is |
|---|---|
| `my_map.yaml`, `my_map.pgm` | occupancy grid built with slam_toolbox on the simulated 2-D lidar (5 cm cells, origin `[-42.5, -4.41]`). The map frame equals the simulator's world frame: the robot starts at the origin with yaw 0 |
| `scene_graph.json` | the raw GroundingDINO + stereo-depth detections: 149 entries `{id, label, x, y, z, count, score}` in the map frame. Many are duplicates or look-alikes (see `docs/EVALUATION.md`) |
| `scene_graph.consolidated.json` | the same detections after `python -m vlm_nav.consolidate`: 46 entries, walls dropped, duplicates merged, piles as `kind: group`. Derived from the file above; the brain produces it on load if you give it the raw file |

Use them:

```bash
cp saved_state/hospital/my_map.yaml saved_state/hospital/my_map.pgm ~/
mkdir -p ~/scene_graph && cp saved_state/hospital/scene_graph.json saved_state/hospital/scene_graph.consolidated.json ~/scene_graph/
scripts/launch_isaac.sh          # opens scene/slam.usd and presses Play
scripts/pipeline.sh start        # saved map (static mode) + Nav2
```

The slam_toolbox pose graph was not saved, so `pipeline.sh` uses `static` mode (identity `map -> odom`), which is exact when the
robot starts where the map was built (Stop, then Play, in Isaac Sim). Check with `scripts/check_map_alignment.py`.
The classes in `scene_graph.json` were chosen for the hospital: wheelchair, desk, door, chair, vending machine, trash can, bed,
cart, computer, wall.
